# StockLens 产品定位与交互原则

## 核心用户

普通投资者：有投资偏好，理解一些金融概念，但未必能将“估值合理、盈利改善、波动较低”等偏好准确表达为数据规则。
产品帮助用户完成「表达偏好 → 澄清含义 → 确认条件 → 核验结果 → 调整对比」。

## 代码与交互取舍

- 保留估值、归母净利润同比、波动率等准确名称，并在条件卡片解释它们如何表达偏好。
- 模糊目标进入澄清；明确的数值直接提取。用户无需先写公式，也无需为未提及的维度补条件。
- 阈值由用户设定，或明确选择示例。示例默认收起，标明用途及未经回测验证，避免暗示统一的优质股票标准。
- 来源区分用户描述、手动调整、用户选择的参考条件、待确认的 AI 建议。
- 结果先展示本次实际执行的条件，再展示入选、排除、数据不足；个股详情提供数值、报告期、数据时间和来源。
- 草稿条件与已执行条件分开。修改草稿不改变旧结果的规则；数据自动更新也不覆盖已展示结果的快照含义。
- 调整条件沿用原数据快照并比较前后规则。用户主动使用最新数据时重新建立比较起点，不将行情变化混入条件对比。
- 当前仅支持三类指标和 AND；未支持的行业、趋势、时间序列要求继续明确展示。

## 本轮调整

- 首页聚焦「投资偏好」与「可核验条件」，减少完全零基础教学式表述。
- 澄清选项使用「关注估值水平 / 盈利增长 / 近期波动」，附简短口径说明。
- 条件卡片始终显示偏好与指标之间的对应关系；阈值示例改为可选展开。
- 结果区增加「本次执行条件」摘要，使用上次实际提交的参数，不使用尚未执行的输入草稿。
- “风险低 / 稳健 / 安全”先澄清可量化含义，不自动替换为波动率或市盈率，也不推断用户经验和风险承受能力。

维持现有视觉和三步工作流，不增加策略回测、交易下单或复杂表达式编辑器。
