# 自然语言澄清与参考条件

## 问题与修复

此前“潜力股”等没有量化定义的目标被放入 `unsupported`，界面直接禁用筛选，且要求用户重新输入专业指标。
现在将模糊目标放入 `clarifications`，与当前不支持的具体限制分开。纯模糊输入显示日常语言引导，不显示“0 项条件”和无效执行按钮。

用户可以选择“公司赚钱比去年更多”“价格相对公司盈利不太贵”“最近价格起伏较小”，也可以用自己的话补充。
点选方向只启用相关条件，不自动填数字或执行筛选；已有明确条件继续保留。
自然语言补充会连同原始描述再次解析，防止丢失原有行业、时间等约束。

空阈值卡片提供参考条件按钮。数字仅在用户点选后填入，并标注“参考条件 · 已选择”，仍可修改。
这些数字是产品内的试用示例，不是经回测验证的标准，也不代表对股票的推荐。
所有真实筛选仍由 Python 对本地快照执行；不能保证一定有股票符合。

## 验证

- 19 项 Python 测试、10 项前端测试及 TypeScript/Vite 构建通过。
- 实际调用官方 OpenAI `gpt-4o-mini` 验证三条输入：
  - “我想找潜力股”：没有启用任何指标，`unsupported=[]`，返回澄清问题。
  - 原描述加“我指的是利润比去年增长至少10%的公司”：仅启用 `profit_min=10`，来源为用户，状态 `ready`。
  - “我想找银行潜力股”：返回模糊目标澄清，同时保留 `unsupported=["银行行业"]`。
- 真实模型三次通过不代表所有表达都已覆盖。浏览器视觉与完整点击流程尚待本地验收；上轮浏览器控制工具无法点击或截图。

## 本地验收

1. 刷新前端；后端需加载新代码（使用 `--reload` 时自动完成）。
2. 输入“我想找潜力股”，解析后应看到“你更看重哪一点？”及三个通俗选项。
3. 点击“公司赚钱比去年更多”，应只启用盈利增长卡片，数值为空。
4. 点击“利润比去年增长至少 10%”，应填入 `10` 并标记已选择参考条件。
5. 点击确认执行，当前 5 只快照应有 3 只符合，仅评估利润增长。
6. 重新解析原句，在补充栏输入“我指的是利润比去年增长至少10%的公司”，继续解析后应直接生成这一条件。
7. 输入“我想找银行潜力股”，即使选择关注方向，也应保留行业未支持提示并禁止执行。
8. 不选参考条件而留空提交，仍应在对应卡片提示补充；手动输入和 AI 建议确认逻辑保持有效。
