## 本轮真实 API 用例

两个提供商均通过以下场景：

1. “利润比去年多两成的公司”：归母利润同比下限 20%。
2. “市盈率不超过20倍，近期股价波动小”：PE 上限 20，波动率阈值为空，等待补充。
3. “市盈率不超过20倍或者ROE至少10%”：保留不支持的 OR，禁止静默变成 AND。
4. “不要银行股，市盈率不超过20倍”：保留不支持的行业排除条件。
5. “市盈率小于十倍，同时大于三十倍”：标记冲突。
6. “营收增长至少5%，利润增长至少10%”：分别提取营收和利润，不混用。
7. “找安全稳健、风险低的股票”：澄清风险含义。
8. “找潜力股，这里潜力指利润比去年增长至少10%”：按已给出的定义提取条件。

可执行且阈值完整的用例继续调用 `/api/screen` 验证。原始运行记录保存于本机 `artifacts/semantic-acceptance.json`（不入库）；可运行 `python backend/verify_acceptance.py --live` 重现，产生 API 用量；使用 `--provider` 和 `--case` 可仅重测失败项。

此前扩展六场景的最终结果为两个提供商各 6/6；OpenAI 早期曾遗漏行业，经必填契约与遗漏检查修复后通过。详细历史见《条件扩展与策略保存》。历史结果和本轮结果分别记录，不将历史调用冒充本次重测。
