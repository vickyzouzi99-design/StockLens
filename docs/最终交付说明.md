## 产品与范围

帮助普通投资者将投资偏好转成可理解、可修改、可核验的筛选条件。支持两个可选 AI 服务、六个数值指标、单一同花顺行业、沪深300快照、逐项筛选依据、同快照条件变化比较及浏览器本地策略库。

执行规则目前为 AND；正 PE/PB 上限、利润/营收/ROE 下限、波动率上限。恢复策略和修改阈值不调用 AI。没有自动交易、历史收益回测、云端策略同步或收益承诺功能。

## 从源码启动

1. 准备 Python 3.10+、Node.js 26（前端测试直接运行 TypeScript）。
2. 在根目录创建 Python 虚拟环境，安装 `backend/requirements.txt`。
3. 将 `.env.example` 复制为 `.env`，填写自己的扶摇及所需 AI 服务密钥。
4. 执行 `python backend/collect_data.py 300`，成功校验后发布数据。仓库不包含私人密钥及本地金融快照。没有快照时后端返回明确的不可用信息。
5. 执行 `python -m uvicorn app:app --app-dir backend --host 127.0.0.1 --port 8000`。开发时可加 `--reload --reload-dir backend`，运行环境须允许访问外部 API。
6. 在 `frontend` 执行 `npm ci`、`npm run dev`。
