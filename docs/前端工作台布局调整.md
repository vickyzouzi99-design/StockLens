# 前端工作台布局调整

本轮批判性参考用户提供的《StockLens 前端布局重构规范 v1.0》，仅调整 React 页面结构、样式及展示状态；不改后端接口、模型提示词、金融字段、条件校验或筛选计算。

## 采用与取舍

- 采用统一1320px容器、24px布局间距、20px主卡片圆角、12px主按钮圆角，以及更紧凑的字号与纵向间距。复用原深海蓝色变量，没有增加 UI 库。
- 第一步保留宽输入卡片。没有为双栏而重复增加说明栏；品牌文案保持“你的选股想法，值得有据可循。”及“以想法定义方向，以数据检验结果。”，主标题从最大57px缩为40px。
- 第二步桌面采用8:4布局：左侧为白色条件编辑区，右侧为实际股票池、数量、条件数、数据状态及执行按钮。条件按行排列，移除独立大卡片与单条件居中造成的空白。
- 1199px及以下概览移动到编辑区下方，避免按钮和指标解释被压窄；小屏进一步将单条条件的说明与数值上下排列。
- 第三步继续全宽表格。数值列与表头右对齐，股票名称左对齐，行间距收紧；保留全部实际字段，窄屏可横向滚动并支持键盘聚焦。
- 不改成三个独立路由或强制向导。原页面是连续工作流，保留条件和旧结果有利于调整对照。
- 不将文档提到的涨跌幅样式扩展为新行情功能，也不加入预计匹配率、收益率等没有真实数据支持的内容。

## 展示交互

解析成功后收起输入区和欢迎文案，保留原需求摘要、实际 AI 来源及“修改需求 / AI 服务”入口。展开后输入、服务选择和重新解析仍可使用；没有修改时可以直接收起。

原有字段错误仍显示在输入旁，筛选请求错误随执行按钮进入概览区。未支持的条件保留阻断提示，并提供直接展开原需求的按钮。

解析期间输入暂时只读、示例按钮禁用，避免请求完成时把用户刚输入的新文字折叠隐藏。已有的服务切换禁用逻辑保持不变。

步骤标记区分描述编辑、条件调整和已执行结果，并使用 `aria-current="step"`。筛选成功后将焦点与视口定位到结果标题；解析成功仍定位条件标题，尊重系统减少动画设置。

## 修改文件

- `frontend/src/App.tsx`：需求摘要、条件/概览结构、展示状态、结果定位、数值表头对齐。
- `frontend/src/App.css`：布局变量、统一尺寸、行式条件、响应式布局及表格密度。
- `frontend/src/index.css`：中文字体回退和原生 select 字体继承。

## 验证与边界

已通过前端11项测试、TypeScript + Vite构建、ESLint。当前 Chrome 可访问性树能读取新的初始页面与服务选择框，300只股票加载状态来自实际接口。

电脑控制仍无法点击（`coordinate input geometry is unavailable`），截图超时；本轮未完成桌面/移动端截图验收和浏览器全流程点击验收，不能将构建成功等同于视觉验收。

待可操作浏览器中检查：

1. 在1440×900和390×844窗口检查输入按钮可发现性、主页面横向溢出，以及表格内部滚动。
2. 解析单条件、双条件和潜力股等模糊目标，确认摘要、条件行、澄清选项及概览正确显示。
3. 编辑需求或切换服务后重新解析；验证文字保留，原条件/结果不冒充新解析。
4. 输入负 PE / 空值并执行，确认定位到字段错误；更正后筛选并定位结果区。
5. 修改阈值再次执行，确认同快照对比、股票详情和来源追踪仍可访问。
