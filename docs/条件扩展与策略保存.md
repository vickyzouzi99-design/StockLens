# 条件扩展与策略保存 · 2026-11-17

## 策略管理闭环更新

此节替代下文早期策略库行为说明。顶部“我的策略”作为独立入口打开右侧管理抽屉；第二步可保存已确认的编辑条件，第三步保存实际执行时的完整快照。保存时只需输入名称。列表支持载入、重命名、复制和确认删除。

策略快照包含全部六项指标（启用状态、固定运算符、阈值和单位）、行业、CSI300 股票池、AND 关系、原始需求及来源服务，另有 ID、名称、创建和更新时间。停用指标保留数值，重新启用不会清空。运算符仍与现有引擎一致，尚未新增 OR 或区间功能。

载入无需 AI 请求，清空旧结果并回到第二步；修改阈值可直接筛选。“保存更改”显式更新当前方案，“另存为新策略”保留原方案。修改后显示未保存状态，旧结果显示条件变更提示。重新解析前确认将替换当前编辑条件。载入其他方案前对当前已载入策略的未保存修改提示确认。

继续使用 `stocklens.strategies.v1` 存储键及版本化封套，单条新记录为 `schemaVersion: 2`；旧记录读取时迁移，原格式未曾保存的停用阈值无法补回。新建最多 30 条，旧库最多 50 条仍可读取，避免升级时删除旧内容。损坏和不兼容数据阻止恢复和覆盖；写入异常显示在保存对话框。仅保存白名单字段，不写入 API Key 或结果。抽屉使用原生模态对话框管理焦点，可按 Escape 关闭。

本轮验证：前端 15 项测试通过，生产构建和 ESLint 通过；未调用 AI API。测试覆盖旧版迁移、停用值保留、启用后正确生成参数、快照差异识别、未知指标和运算符拒绝以及额外敏感字段不被写入。浏览器逐项交互及视觉验收仍未完成。

按用户选定顺序实施：1 条件冲突识别，2 策略保存和恢复，3 PB / ROE / 营收增长，4 行业筛选。

## 使用变化

- 自然语言中互相矛盾的数值要求会显示冲突双方，并阻止执行。修正描述后重新解析，不自动选择其中一个要求。对明确撤回、改写和 OR 要求由语义解析处理；正则只对明确的同方向叙述补充校验，不代表能够证明任意自然语言无矛盾。
- “我的策略”保存在当前浏览器，可恢复、重命名和删除；最多 50 条。结果区“保存这组条件”保存最近实际执行的阈值与行业。恢复后需要重新确认执行，使用最新可用快照。原描述只是参考，以保存的条件为准；不保存旧股票结果和密钥，不支持跨设备同步。
- 新增正市净率 PB MRQ 上限、报告期加权平均 ROE 下限、营业收入同比增长率下限。包含说明、输入范围校验、参考阈值、逐项核验、策略保存和条件变化比较。
- 行业来自扶摇 `ths-index-list-by-stock?type=industry`，使用同花顺分类，仅支持目录中的单个行业。行业与数值要求全部同时满足；科技、大消费等宽泛概念不能自动视为一个行业。
- 行业分类缺失时该项为 UNKNOWN；所有其他条件通过时股票为“数据不足”，已有明确不符合的条件时为“未符合”。行业查询时间及请求 ID 可在详情查看，查询时间不冒充分类关系生效时间。
- 时间按 Asia/Shanghai 格式化，以 `(GMT+8)` 标注，顶部数据采集时间仍在已加载股票数旁。

## 数据口径

- PB 使用估值接口 `pb_mrq`；负值或零值不视为低估。
- ROE 使用 `index_weighted_avg_roe` 披露值，不自行年化。
- 营收同比使用 `calculate_operating_income_yoy_growth_ratio`，缺失时才尝试 `operating_income_yoy_growth_ratio`。
- 同一只股票的三项财务指标使用同一个报告期，不为了补齐某个字段混用不同期数。最新目标期完全没有三项数据时才回退前期；选定期的缺失字段保留 null。
- 新采集快照的六项数值指标及行业覆盖率均参与发布校验，默认门槛 80%。新快照通过校验后原子发布，历史快照保留。
