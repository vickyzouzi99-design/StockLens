## 浏览器准备

需要已采集的真实沪深300快照及Python/Node依赖。首次安装浏览器：

    cd frontend
    npx playwright install chromium
    cd ..
    .\.venv\Scripts\python.exe backend\prepare_browser_acceptance.py --prepare

准备脚本只写 artifacts/browser-acceptance.sqlite3 和临时凭证，不修改日常账号库。注册用例的邀请码是一次性的，每轮开始前重新准备。分别启动隔离后端和前端：

    $env:STOCKLENS_ACCOUNT_DB='C:\StockLens\artifacts\browser-acceptance.sqlite3'
    $env:STOCKLENS_CORS_ORIGINS='http://127.0.0.1:5174'
    .\.venv\Scripts\python.exe -m uvicorn app:app --app-dir backend --port 8001

    $env:STOCKLENS_API_TARGET='http://127.0.0.1:8001'
    npm --prefix frontend run dev -- --host 127.0.0.1 --port 5174

若根目录.env显式指定账号库，以该文件为本地优先配置；验收前确保隔离服务指向测试库，不能对真实用户库运行注册/修改密码测试。

不调用AI的界面组：

    cd frontend
    npx playwright test account-ui.spec.ts multi-industry.spec.ts first-fold.spec.ts industry-save.spec.ts edit-cancel.spec.ts login-footer.spec.ts

默认结果列表和零结果提示单独验收：

    npx playwright test result-default.spec.ts

这些用例使用真实后端、账号持久化和金融快照；部分条件通过保存快照预置以跳过AI，不假称验证了自然语言理解。

## 明确付费的验收

配置相应密钥且后端可联网后，手动执行：

    npx playwright test ai-review.spec.ts
    npx playwright test workflow.spec.ts

前者调用OpenAI与DeepSeek各一次；后者调用DeepSeek一次，验证从自然语言到保存恢复的完整工作流。不在CI自动运行，不为布局修改重复收费调用。backend中的verify_persona_live.py与verify_extended_live.py也会直接产生模型用量；verify_acceptance.py针对运行中的HTTP服务，启用登录时需要有效会话或隔离本地模式，不应拿未登录401当成模型故障。
