## 用户体验

- 移除页面上方独立账号条；悬浮导航最右侧仅显示头像，菜单包含“我的策略”“我的账号设置”“退出登录”。菜单支持外部点击关闭、Escape和键盘聚焦。
- 登录和邀请码注册统一使用深海蓝、品牌宣传语、同一组表单控件，显示“内测版”。登录、注册、工作台共用同一个页脚组件。
- 账号设置读取当前用户名、当日调用量和额度，可核对旧密码后更新密码。更新后撤销旧会话，当前浏览器获取新会话；测试只修改隔离测试账号。
- 修正首屏副标题被 margin 简写覆盖的问题，标题、副标题、输入卡片、流程和示例居中。
- 规则采用紧凑行，默认优先显示指标、阈值、来源和移除操作；完整解释仍保留在原帮助入口，错误、参考阈值及 AI 建议确认不删除。桌面验收中六项行高均小于135px。
- 第二步浅色保存按钮在执行左侧，宽度小于主按钮；结果区“保存策略参数”与条件标题分列，保留足够间距，保存 executedSnapshot。

## 行业多选

行业内部采用任一匹配，与数值条件仍全部同时满足。支持自然语言提取、搜索复选、清空、策略保存和恢复，以及同快照条件比较。旧的单行业字符串继续可用，多行业为 industry 代码数组；不支持跨指标 OR 或排除条件。顺序和重复项被规范化，不产生虚假的未保存状态。目录缺失或未完整提取时继续阻断，不能默默删除其中一个行业。

## 有用的溯源

个股详情默认展示本次快照采集时间、启用指标的数据来源、估值口径、财务报告期、行业查询时间和波动率计算方式；只在快照记录了完整有效价格窗口时提供21个前复权收盘价，用户可据此复算20个收益率的样本标准差。缺失字段显示未知或未记录，不补造时间、价格或数据认证。

原始请求和快照编号保留在默认折叠的“技术记录”中，用于反馈问题，可复制，不再充当主要溯源内容。所有说明从原始字段和确定性规则生成，不使用 AI 编造来源。

## AI 可选补充

原有解析继续保留用户明确条件。一次解析可额外返回最多两项可选指标，说明其与当前需求的关系和局限。它们不进入 active_metrics、parameters 或数值约束；点击加入后需要用户设置阈值才可执行。用户限定“只看”、存在冲突、待澄清或不支持要求时不展示补充。原有 AI 建议阈值仍需单独确认。

实测两个提供商各一次：输入“PE不超过30、利润增长至少10%，请建议其他补充指标”，两者均保留原参数并给出两项可选补充；点击加入未增加 API 请求。不是通过模型伪造股票或指标数值来制造智能感。

## 可重复验收

先运行 `python backend/prepare_browser_acceptance.py --prepare`，生成独立测试数据库及私有测试凭证到 artifacts，不操作正常账号库。验收后端需指向 artifacts/browser-acceptance.sqlite3，在8001端口启动；前端设置 STOCKLENS_API_TARGET=http://127.0.0.1:8001 并在5174启动。然后：

```powershell
cd frontend
npx playwright test account-ui.spec.ts multi-industry.spec.ts
```
