## 完成的修复

- 条件调整复用原快照。`/api/screen`、`/api/compare` 支持32位快照 ID，读取历史文件；原文件不可用返回409，非法 ID 返回422。不会自动切换数据。
- 页面增加“使用最新数据重新筛选”，主动换数据时清空旧条件对比，建立新的比较起点。
- “风险低 / 稳健 / 安全”进入澄清，不能直接替换为波动率；波动方向说明明确低波动不等于低风险或未来上涨。
- 采集失败从结束时算起冷却10分钟。日历失败同样持久化重试记录；损坏的刷新状态文件不会阻止后续采集恢复。
- API 和前端生产部署配置补齐：同域请求、可配置 CORS、API systemd 服务、Caddy 模板、独立密钥示例及部署说明。
- 本地开发继续使用项目 `.env` 优先；生产服务明确设置 `STOCKLENS_ENV=production`，服务环境优先。
- 修正原有 `useExample` 普通事件函数触发的 React Hook lint 误判，改名 `selectExample`。
