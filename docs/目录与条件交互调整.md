## 交互变化

- 数值校验在字段失焦或执行筛选时触发，错误显示在对应输入框下方。
- 修正数值后错误随输入更新；多个条件出错时各自提示，执行时聚焦第一个错误字段。
- 每次解析成功后定位到“确认筛选条件”，只展示启用的条件卡片。
- 去掉重复成功通知和集中待填清单，将 AI 解析说明改为默认收起的详情；未支持的条件仍直接展示并阻止执行。
- 条件区顶部间距由桌面 65px / 手机 47px 缩为 28px / 24px；卡片标题上下留白缩小。
- 解析失败仍在描述区提示，筛选请求失败在执行按钮附近提示。

## 本地验收步骤

1. 输入“我想找市场估值偏低的股票”，点击“解析选股需求”。应自动定位到条件区，只出现估值卡片，数值为空，解析说明默认收起。
2. 填入 `-2` 后移开焦点或执行筛选。错误应紧邻估值输入框，输入框边框变色，不应在页面上方显示数值错误。
3. 改为 `20`。错误应立即消失；执行后按当前实际快照逐项核验结果，数量应与当前加载的股票池一致（已扩容到沪深300）。
4. 添加盈利增长和近期波动，分别输入 `10001`、`-1`，执行后应在各卡片内显示对应范围错误，并定位第一个错误输入框；移除条件后不应继续阻止筛选。
5. 清空一个启用条件并执行，应在该输入框下提示填写；利润增长 `0` 或波动率 `0` 是合法边界，PE `0` 不合法。
6. 点击指标旁的 ⓘ，确认说明悬浮显示、不撑高相邻卡片，Esc 或点击外部可关闭。
7. 将窗口缩窄，确认条件卡片改为单列，字段错误和执行按钮可见，无横向页面溢出。
8. 输入包含未支持条件的描述，确认仍显示具体限制并禁用执行，不能静默遗漏用户条件。

构建和 Python 测试通过不能替代以上页面交互验收。
